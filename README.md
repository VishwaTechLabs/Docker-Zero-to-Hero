## Repository Structure

- `01-Fundamentals` — Docker concepts, containers, VMs, architecture
- `02-Installation` — Docker Desktop / Engine setup
- `03-Docker-CLI` — commands and command reference
- `04-Images` — image lifecycle and tags
- `05-Containers` — container lifecycle, logs, exec, inspect
- `06-Dockerfile` — writing Dockerfiles
- `07-Dockerfile-Instructions` — FROM, RUN, COPY, CMD, ENTRYPOINT, etc.
- `08-Build-Cache-and-Layers` — layers and build optimization
- `09-Multi-Stage-Builds` — production image optimization
- `10-Networking` — bridge, host, ports and container communication
- `11-Volumes-and-Storage` — volumes and bind mounts
- `12-Docker-Compose` — multi-container applications
- `13-Registries` — image registries
- `14-Docker-Hub` — Docker Hub workflow
- `15-AWS-ECR` — Amazon ECR workflow
- `16-Security` — Docker security and image scanning
- `17-Logging-Monitoring` — logs, stats and health checks
- `18-Troubleshooting` — common problems and solutions
- `19-Best-Practices` — production guidance
- `20-GitHub-Actions-Docker` — Docker CI/CD
- `21-Docker-Kubernetes` — relationship between Docker and Kubernetes
- `22-Docker-Terraform-Ansible` — DevOps toolchain integration
- `23-Labs` — hands-on labs
- `24-Assignments` — student assignments
- `25-Projects` — real-time projects
- `Dockerfiles` — reusable Dockerfile examples
- `Compose` — Compose examples
- `Cheat-Sheets` — quick references
- `Interview-Questions` — interview preparation
